# 图阅PDF（TuYuePDF）

图阅PDF 是基于 TuYuePDF 的多格式阅读器，融合看图王的鼠标交互体验，支持 PDF、EPUB、MOBI、CBZ、CBR、FB2、CHM、XPS 和 DjVu。
许可证沿用上游 (A)GPLv3，部分代码采用 BSD 许可证（见 AUTHORS）。
